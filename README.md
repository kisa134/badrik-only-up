# 🐕 Badrik Wars

3D игра с бульдогом на Three.js

## Особенности
- Управление персонажем в 3D пространстве
- Различные анимации (бег, ходьба, прыжки, сидение)
- Выбор скинов персонажа
- Интерактивное меню

## Управление
- **WASD** - движение
- **Shift** - ходьба (вместо бега)
- **Пробел** - прыжок
- **Мышь** - управление камерой
- **1** - сесть
- **2** - лечь
- **3** - почесаться

## Запуск
Откройте `index.html` в браузере или запустите локальный сервер.
